# Repositorio de Algoritmos, Estructuras de Datos y Programación en Java

Este repositorio contiene diversos proyectos, módulos, ejercicios prácticos y aplicaciones desarrolladas en **Java** enfocadas en el aprendizaje, práctica y consolidación de conceptos de algoritmos, estructuras de datos, programación orientada a objetos (POO), interfaces gráficas (GUI) y desarrollo web básico.

## Estructura del Repositorio

El repositorio se compone de múltiples submódulos y proyectos independientes:

- **AlgEstrDat/**: Módulo principal que contiene implementaciones y ejercicios orientados a:
  - Estructuras de datos lineales y no lineales (Pilas, Colas, Listas Enlazadas, Árboles Binarios, ABB, AVL, Grafos).
  - Algoritmos de búsqueda y ordenamiento (Búsqueda Binaria, etc.).
  - Repasos diarios y retos de programación estructurada y POO.
- **RepasoAlgorit/**: Ejercicios de repaso sobre estructuras de control, bucles, listas y programación orientada a objetos básica.
- **pryBar/** y variantes (**pryBarGUI**, **pryBarIngGUI**, **pryBar**): Proyectos basados en juegos de cartas (Poker, Siete y Media, Adivina Carta, etc.), diseñados para practicar diseño orientado a objetos avanzado, lógica de juegos y interfaces gráficas de usuario (Swing).
- **pryMeNum/**: Algoritmos numéricos, búsqueda binaria y métodos de cálculo (ej. punto fijo).
- **pryPoo/**: Ejercicios específicos sobre Programación Orientada a objetos en Java.
- **pryTabl/**: Simulación de un tablero de ajedrez y piezas (Rey, Reina, Torre, etc.).
- **pryTreRay/**: Implementación del clásico juego Tres en Raya (Tic-Tac-Toe) con lógica para jugador y computadora (IA básica).
- **pryWeIntJ/**: Pequeña interfaz web interactiva (HTML, CSS, JS).

## Tecnologías Utilizadas
- **Lenguaje**: Java (JDK 11 / 17 / 21)
- **Herramientas de Construcción**: Maven
- **Interfaz Gráfica**: Java Swing / AWT
- **Control de Versiones**: Git
