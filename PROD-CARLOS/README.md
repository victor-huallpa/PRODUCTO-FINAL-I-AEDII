# PROD-CARLOS - Subsistema de Estructuras de Datos Avanzadas y Algoritmos

Este subproyecto contiene implementaciones avanzadas en Java orientadas a la resolución de problemas algorítmicos complejos, manipulación de estructuras de datos y aplicaciones prácticas.

## Módulos Incluidos
- **DirectorioBST/**: Implementación y gestión de estructuras basadas en Árboles Binarios de Búsqueda (BST).
- **EditorConPilas/**: Simulación de un editor de texto o sistema de deshacer/rehacer (Undo/Redo) utilizando Pilas (Stack).
- **RutaMasCorta/**: Algoritmos de rutas y grafos para la optimización de trayectorias (ej. Dijkstra / teoría de grafos).

## Tecnologías
- **Java** (JDK 11+)
- **IDE**: IntelliJ IDEA
